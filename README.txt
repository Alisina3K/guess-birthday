Guess Birthday - installable offline app (PWA)

1. Upload this whole folder to any HTTPS static host (e.g. Netlify Drop, GitHub Pages).
2. Open the link once while online.
3. Install:
   - Windows (Chrome/Edge): install icon in the address bar
   - Android (Chrome): menu > Install app
   - iPhone (Safari): Share > Add to Home Screen
After that it works fully offline.
